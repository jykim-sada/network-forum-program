당일 순서

  1. 12:00 운영진 콘솔에서 단계를 「등록」에 두고, 스크린을 LED에 전체화면(F)으로 띄웁니다. 참가자가 스크린의 QR을 휴대폰으로 찍어 한 줄씩 올립니다.
  2. 12:30 「1부」로 넘기면 스크린이 1부 장표로 바뀝니다. 콘솔 「다음」으로 영상·인사말·발표자·기념촬영·좌석 안내 장을 차례로 넘깁니다(발표자 PPT로 전환해도 됩니다).
  3. 13:40 「2부 시작」 → 2부 간지·토론 주제 4개 장을 「다음」으로 넘기며 주제를 안내합니다.
  4. 13:40 「토론 1라운드」를 누르면 40분 타이머가 시작됩니다. 기록자 9명이 토론 내용을 기록합니다. 14:20 「토론 2라운드」 → 이동 안내 장(참가자만 이동, 타이머 꺼짐) → 14:25 「다음」으로 진행 화면에 들어가면 새 40분 타이머가 시작됩니다.
  5. 15:05 「휴식·취합」 → 입력이 마감되고, 콘솔에서 「분석 실행」을 누릅니다. 테이블별 정리가 자동으로 만들어집니다.
  6. 15:25 「결과공유」 → 콘솔의 이전·다음·「같은 의견」으로 스크린 장표를 넘깁니다. 15:50 「마무리」, 보고서 PDF 저장.
